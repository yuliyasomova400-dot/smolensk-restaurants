# Рестораны Смоленска

Мобильный концепт для согласования с заказчиком. Меню «Гуру», корзина и демонстрация бронирования.

Бронирование работает только в памяти текущей страницы. Контакты не отправляются, реальные заказы и платежи не подключены. Общая серверная база доступна только в отдельной локальной версии.

Изображения и меню взяты с официальных сайтов ресторанов.
